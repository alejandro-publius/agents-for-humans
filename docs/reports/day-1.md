### Block E

- **E1 Interrupt.** Verified with `inspect` against strands-agents 1.55.1: `strands.vended_plugins.steering.core.action.Interrupt(reason: str)` is a real steering action; the vended handler calls `BeforeToolCallEvent.interrupt(name, reason)` which raises `InterruptException` until a response exists; the agent returns `stop_reason == "interrupt"` with `result.interrupts`; a resume is `agent([{"interruptResponse": {"interruptId": id, "response": value}}])`; `FileSessionManager` persists messages, `agent.state`, and the interrupt state, so a new agent instance with the same session id can resume. After-dark and last-train are now real Interrupts: the run pauses before `draft_message`, a decision card (BART's option, the policy engine's minutes and basis, flags, the KB source URL and scrape time, every rejected option with its one-line reason) is written to the rider's inbox as a `pending_decision` row, `POST /decisions/{row}` answers it, the run resumes from the persisted session, and the answer is stored in `agent.state["decisions"]` and in the rider's preferences so the same case does not interrupt again (accept proceeds silently; decline steers to mitigation_trip silently). `pytest tests/test_strands_mechanics.py` printed `4 passed` (after-dark case: exactly one Interrupt, no plan, one model turn; resume with accept: plan with the policy top option; identical case in a new agent on the same session: Proceed, zero Interrupts). `pytest tests/test_app.py` printed `4 passed` including the inbox card and the resume endpoint. `make demo-one ARGS=--after-dark` printed the pause, the card, `RESUMED : final plan option=transit`, and `same case : paused=False interrupts=0`.
