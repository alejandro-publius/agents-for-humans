# Devpost submission checklist

**Hackathon:** [Agents for Humans](https://agentsforhumans.devpost.com/) (AWS, managed by Devpost)
**Deadline:** **Monday, September 14, 2026, 5:00 pm PDT**
**Judging:** Sept 15 – Oct 8, 2026 · **Prizes:** $40k total; $10k grand prize; $5k / $3k / $2k per track

## Required (all must be done before the deadline)

- [ ] **Devpost project page** with text description: what it does, who it's for, how it works
- [ ] **Track selected:** Everyday / Professional / Good Neighbor
- [ ] **Public repo URL** with all source, assets, and setup instructions needed to run it
- [ ] **MIT or Apache license file** visible in the repo's About section (this repo: MIT ✅)
- [ ] **README** (this repo has one; keep it accurate to what the demo shows)
- [ ] **Architecture diagram** (source in `docs/architecture.md`; export a PNG for Devpost)
- [ ] **Demo video ≤ 5 minutes**, public on YouTube or Vimeo, that
  - [ ] shows the project working end to end
  - [ ] pitches (1) the problem, (2) who it's for, (3) why it matters
  - [ ] slides / screen recording / voiceover are fine; no camera needed
- [ ] **AWS Builder ID** for the submitter
- [ ] Team **Representative** named on Devpost (one person submits on behalf of the team)

## Optional, but scored

- [ ] **Live demo link** (raises Technical Implementation score)
- [ ] **Amazon Bedrock AgentCore deployment** (raises Technical Implementation score; see `deploy/`)
- [ ] **builder.aws.com blog post(s)** about the build journey and AWS usage, with
      "Agents for Humans" in the title, published before the deadline (+0.2 each, max +0.6)

## Rules that bite

- **New projects only.** Everything must be built during Aug 10 – Sep 14, 2026. Disclose any
  pre-existing code you incorporate. Frameworks, libraries, templates, and AI coding assistants are fine.
- The project must **install and run** as shown in the video and description.
- Third-party APIs/data must be used under their terms.
- All materials in English.
- AWS promotional credits: the organizer reports all credits have been disbursed (form closed Sept 11).

## Judging criteria (equally weighted, 1–5 each; bonus up to +0.6)

1. **Technical Implementation.** Thorough, skillful, non-trivial use of Strands Agents. Live demo / AgentCore helps.
2. **Design.** A complete, coherent product experience, not a proof of concept.
3. **Potential Impact.** A credible, specific case for a real problem and a real audience, actually addressed.
4. **Creativity & Originality.** Non-obvious use of Strands; genuine understanding of the problem space.
5. **Presentation.** Video shows it working end to end; pitch covers problem / who / why; easy to follow.
